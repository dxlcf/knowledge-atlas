# 沉淀知识

先读取仓库根目录的 [AGENTS.md](../../../AGENTS.md)，遵守其中的写入、确认和来源约定。

## 工作流程

1. 确定待沉淀的回答、对话片段或材料。对“刚才的回答”使用当前上下文中的对应内容；上下文缺失时请求提供原文，不猜测。
2. 提取有长期价值的概念、机制、实践要点和边界。去掉聊天口吻、重复解释和临时排障噪声，保留对结论至关重要的条件与反例。
3. 先读取相关 Maps，再检索 Notes 中的同义概念和别名。一个知识点优先复用已有笔记；多个独立知识点可拆分，并以已有文件链接关联。
4. 按 [Notes 格式](../../../notes/README.md) 写入非破坏性增量。已有覆盖且没有新信息时不改动。对相互冲突的结论说明证据和适用条件，重要覆盖先展示具体建议等待确认。
5. 继承能够核实的原始来源；未经核实的对话结论注明“来自对话，待验证”，不伪造外部引用。需要外部验证却无法访问时保留明确限制。
6. 给出每份新增笔记的大纲归属和拟插入条目；无合适大纲时提出最小主题建议。确认具体方案后再调整 Maps。

## 交付

列出实际新增或更新的文件、相对已有内容的增量、未验证的结论及待确认的大纲方案。检查相对链接，说明暂未纳入大纲的笔记；不把未执行的建议列为已完成。
