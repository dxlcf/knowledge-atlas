# 优化知识大纲

先读取仓库根目录的 [AGENTS.md](../../../AGENTS.md)，遵守其中的写入、确认和来源约定。

## 工作流程

1. 读取用户指定主题的大纲；未限定范围时检查 Maps 及 Notes 文件清单，再按需读取笔记，不无差别加载全部内容。没有主题大纲时说明现状，根据实际笔记提出最小入口建议；空仓库不凭空设计领域体系。
2. 检查重复或近义条目、层级混杂、职责重叠、断链、未被大纲索引的笔记，以及标题和笔记内容不符的问题。目录 README 不作为孤立知识笔记。
3. 区分结构缺陷与学习建议。断链是可验证问题，推测的知识缺口只作为建议；知识库缺少记录不代表用户尚未掌握。没有用户反馈时保持“未评估”。
4. 提供最小变更方案，逐项列出问题依据、受影响文件、修改前后条目与理由。移动或重命名时查找入链，并将链接修复纳入同一方案；笔记合并、重要覆盖或删除单独说明影响。
5. 检查或优化请求本身不代表已确认具体修改。先返回可审阅方案，收到确认后只执行获确认部分；用户已确认同一具体方案时直接执行，无须重复询问。
6. 执行后检查相对链接和差异，保留原有来源及用户给定的掌握状态。不要为补齐大纲创建空笔记或自动填充未经要求的知识。

## 交付

检查阶段返回问题、证据及待确认方案，无问题则说明检查范围与结果。执行阶段报告实际变更、链接修复和仍需用户判断的事项；未确认部分继续保持原状。
