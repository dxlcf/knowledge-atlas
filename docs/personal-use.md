# 个人使用指南

[返回项目首页](../README.md)

本仓库提供方法与模板，个人笔记放在你自己的仓库中。无需安装依赖，也不用提前设计知识分类。

## 1. 准备自己的仓库

先将模板克隆到本地（也可以用 Git 客户端）：

```shell
git clone https://github.com/dxlcf/knowledge-atlas.git my-knowledge-atlas
```

在 Agent 中打开 `my-knowledge-atlas`。准备好自己的空远程仓库（建议私有），再发送下面的指令，替换其中的地址：

> 请将当前仓库的 origin 改为 `<我的远程仓库地址>`，并将当前分支推送到我的仓库。不修改仓库文件。如果目标仓库已有内容，先检查并告知我，不覆盖或强制推送。

绑定后即可使用，无须修改 README、AGENTS.md 或其他配置。后续直接在 Maps 中建立知识大纲，在 Notes 中积累知识点，需要同步时让 Agent 提交并推送到自己的仓库。

## 2. 随手记录

在 `inbox/` 新建 Markdown 文件，写下学习发现、想法或问题；有来源就附上链接。格式随意，不必先分类，也可以让 Agent 帮你记录。

## 3. 需要时让 Agent 整理

> 请按 AGENTS.md 和对应 Skill 整理 inbox/ 中尚未处理的笔记。

Agent 会检索已有内容、去重并沉淀笔记。需要新增或调整大纲时，会先给出方案，你确认后再执行。整理完成后，从 `maps/` 浏览和回顾知识。

其他常用说法：

- “将刚才的回答整理到知识库。”
- “分析这篇文章，告诉我有哪些值得学习的新内容：URL。”
- “把这次资料分析保存到 Sources。”
- “检查当前知识大纲。”

普通问答不会自动保存。你只需记录、提出需求、查看结果；具体整理规则由 Agent 遵循。

方法更新无需追着同步。以后有需要时，再选取新版规则或 Skill，保留自己的笔记和定制即可。
