# Inbox · 临时笔记

[返回仓库首页](../README.md)

自由记录想法、问题、学习发现和知识要点，不必提前分类。推荐文件名为 `YYYY-MM-DD-short-topic.md`，也可以沿用自己的命名方式。

可复制以下格式，按需删减：

```markdown
# 记录主题

## 原始记录

记录想法、知识要点或疑问。

## 来源（如有）

粘贴资料 URL、标题或对话背景。

## 希望解决的问题

说明需要核实、实践或整理的内容。
```

示例指令：“整理 `inbox/` 中今天的笔记”“将这份笔记合并到现有知识中”。如果“最近”无法从文件日期判断，Agent 会说明选取范围或请求澄清。

整理后默认保留原文，追加已落实的目标笔记链接与处理范围。未解决的问题继续保留；仅分析过或仍待确认的部分不标记为完成。清理或删除原文需要确认具体方案。
