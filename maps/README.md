# Maps · 知识大纲

[返回仓库首页](../README.md)

此目录保存按主题组织的知识地图，目前尚未创建主题。新主题由实际学习内容决定，确认后再创建；主题较多时可在本页追加入口。

大纲保留知识层级、简要状态以及子纲和笔记的链接，详细解释放入 Notes。没有笔记的知识点使用纯文本，避免空文件与无效链接。

大纲可以跨文件分层。内容较少时用一页；子主题有独立的检索范围、可被其他主题复用，或展开后影响总纲导航时，考虑拆成子纲。总纲保留主题边界和入口，子纲展开各自的知识点，并通过相对链接返回上级或关联其他主题。

每个大纲目录以目录内的 `README.md` 作为唯一索引。子主题需要独立目录时，把该子主题的总纲和子纲集中在该目录，上级索引指向它的 `README.md`。单页主题可以直接使用 Markdown 文件。

例如，AI 全栈的目录可用 `maps/ai-full-stack/README.md` 作为总纲，前端和后端子纲与它同目录；Agent 若拆成多个文件，则放在 `maps/ai-full-stack/agent/`，以该目录的 `README.md` 作为入口。Agent 子纲仍通过相对链接引用通用基础。

建议状态：**未评估 / 待学习 / 学习中 / 已掌握**。由用户反馈决定，不按笔记数量或完整程度推断。

最小格式（以下为示意，不是已创建的大纲）：

```markdown
# 主题名称

一句话说明范围与边界。

## 知识结构

- 子主题
  - [已有知识点](../notes/concept.md) — 未评估
  - 尚未学习的知识点 — 待学习

## 待探索

- 需要澄清的问题或需要实践验证的机制。
```

只有目标大纲或笔记实际存在时才能加入链接。新增大纲、添加索引或调整层级前，Agent 会展示具体方案，确认后执行。
