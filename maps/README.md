# Maps · 知识大纲

[返回仓库首页](../README.md)

此目录保存按主题组织的知识地图，目前尚未创建主题。新主题由实际学习内容决定，确认后再创建；主题较多时可在本页追加入口。

大纲只保留知识层级、简要状态和笔记链接，详细解释放入 Notes。没有笔记的知识点使用纯文本，避免空文件与无效链接。

建议状态：**未评估 / 待学习 / 学习中 / 已掌握**。由用户反馈决定，不按笔记数量或完整程度推断。

最小格式（以下为示意，不是已创建的大纲）：

```markdown
# 主题名称

一句话说明范围与边界。

## 知识结构

- 子主题
  - [已有知识点](../notes/concept.md) — 未评估
  - 尚未学习的知识点 — 待学习

## 待探索

- 需要澄清的问题或需要实践验证的机制。
```

只有目标笔记实际存在时才能加入链接。新增大纲、添加索引或调整层级前，Agent 会展示具体方案，确认后执行。
