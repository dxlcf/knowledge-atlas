# Sources · 外部资料

[返回仓库首页](../README.md)

保存外部资料的精炼分析与引用，不镜像完整文档或项目。单纯请求分析时默认在对话中返回；明确要求保存后才创建或更新文件。

可复制的分析格式：

```markdown
# 资料标题

## 来源与范围

- 原始链接：实际 URL
- 分析日期：实际日期
- 版本或提交：能确认时填写
- 实际阅读范围：章节、文件或实现入口
- 限制：未访问、未验证或未覆盖的部分

## 与现有知识的比较

| 知识点 | 覆盖情况 | 本地依据 | 增量与来源定位 |
| --- | --- | --- | --- |

## 阅读建议

按优先级列出值得精读的章节或实现、预期收获及必要前置知识。

## 待验证问题

区分资料原述与分析推断。
```

覆盖情况可用“已覆盖 / 值得新增 / 需要深化 / 暂不相关 / 待核实”。现有知识库为空时明确说明比较基线为空，不将没有记录等同于用户不会。

同一资料优先更新已有分析；版本差异有价值时记录差异。分析文件不自动授权更新 Notes 或 Maps，需要沉淀时另按用户要求处理。
