# Notes · 精炼知识

[返回仓库首页](../README.md)

每份笔记围绕一个明确的知识点，优先补充已有笔记。保存可长期复用的结论，不直接堆放教程或完整聊天记录。

推荐最小格式，按内容需要删减章节，无须填写空占位：

```markdown
# 知识点名称

## 核心结论

用简短文字说明是什么、解决什么问题。

## 机制与实践

关键原理、适用条件和必要示例。

## 边界与注意事项

限制、常见误区、尚未验证的推断。

## 关联知识

链接到已经存在的相关笔记或知识大纲。

## 参考来源

列出支持结论的原始资料链接与必要定位；来自对话且未经核实时明确标注。
```

不强制元数据或掌握状态。主题掌握程度在 Maps 中维护；来源分析在 Sources 中维护，笔记仍应尽量保留支持关键结论的原始引用。

沉淀后由 Agent 提供大纲归属建议，确认后建立索引。暂未关联的笔记会在交付时明确说明。
